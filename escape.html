플레이 방법

· 시작하면 역할(A 기획 · B AE · C 디자이너 · D 경영지원)이 배정돼요. 인원이 적으면 한 사람이 두 역할을 맡아요.
· 역할마다 보이는 단서가 달라요. 내 화면에 없는 단서는 동료에게 물어보세요.
· 화면 속 빛나는 곳을 누르면 퍼즐이 열려요. 화면을 길게 누르거나 더블클릭하면 동료 화면에 "여기 봐" 핑이 가요.
· 힌트는 팀당 3번, 쓸 때마다 2분이 더해져요. 기록은 클리어 시간 + 힌트 페널티예요.
